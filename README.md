# Nakhon Si Thammarat Trip Planner

เว็บไซต์แพลนเที่ยว 9–11 มกราคม 2570 (2027)

## Deploy บน Vercel
1. แตกไฟล์ ZIP นี้
2. เข้า https://vercel.com/new
3. เลือก Import Git Repository (ถ้าอัปขึ้น GitHub แล้ว) หรือใช้ Vercel CLI
4. สำหรับเว็บ static นี้ ไม่ต้องตั้ง Build Command หรือ Output Directory เพิ่มเติม
5. Deploy ได้เลย โดยให้ `index.html` อยู่ที่ root

## Local preview
เปิด `index.html` ใน browser ได้โดยตรง

หมายเหตุ: ภาพสถานที่ 6 ภาพเป็นภาพประกอบที่สร้างขึ้น ไม่ใช่ภาพถ่ายยืนยันสถานที่จริง
