# Nakhon Si Thammarat Wedding Trip Planner

เว็บไซต์แพลนเที่ยวและร่วมงานแต่ง 9–11 มกราคม 2570 (2027)

## Deploy บน Vercel
1. แตกไฟล์ ZIP นี้
2. อัปโหลดทุกไฟล์และโฟลเดอร์เข้า GitHub repository (รวม `assets/`)
3. Import repository ที่ https://vercel.com/new
4. Framework Preset: Other; Build Command: เว้นว่าง; Output Directory: เว้นว่าง (root)
5. Deploy

## ข้อมูลเที่ยวบิน (อัปเดต)
- ขาไป 9 ม.ค. 2570: Thai VietJet VZ334, BKK → NST, ตารางเผยแพร่ 13:10–14:30
- ขากลับ 11 ม.ค. 2570: Thai VietJet VZ335, NST → BKK, ตารางเผยแพร่ 15:00–16:20
- ลิงก์ติดตามเป็น external tracker; ไม่ใช่ live status feed ฝังในเว็บ และตารางอาจเปลี่ยนแปลง
- ตรวจสอบเวลาและสถานะจริงจาก e-ticket/สายการบินก่อนเดินทาง

## หมายเหตุ
- ภาพการ์ดเชิญ `assets/wedding-invitation.png` มาจากผู้ใช้
- ภาพสถานที่บางภาพโหลดจากแหล่งออนไลน์
- อุณหภูมิเป็นค่าเฉลี่ยภูมิอากาศเดือนมกราคม ไม่ใช่พยากรณ์เฉพาะวันที่ 9–11 มกราคม 2570
- Google Maps ของ Luca, Aiyara และเขาพลายดำใช้ลิงก์ค้นหาชื่อสถานที่ เนื่องจาก short link เดิมไม่สามารถ resolve เพื่อตรวจ pin ได้
